# Vaishak & Nisha: wedding invitation

A one-page wedding invitation site built by Sarastra Labs with Next.js 16, React 19, Tailwind CSS 4, GSAP and Lenis.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm run start
```

## Edit the content

Everything a person edits is in `src/data/invite.ts`: names, the schedule (Mehendi, Marriage, Reception) with times and Google Maps links, the story questions and answers, the dress code and the FAQ. Photos are in `public/img`, the film in `public/video`, the couple illustration in `public/art`, and dress code examples in `public/dress`.

## Notes

- The site is marked `noindex` while it is a work in progress.
- The photos and film come from the couple's pre-wedding shoot. They belong to the photographer and the couple, so please do not reuse them elsewhere without permission.
- Visual references (envelope, torn paper, wax seals) were drawn from scratch in code and SVG.
